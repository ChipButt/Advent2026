# Advent 2026

A mobile-first digital Advent calendar app for December 2026.

## Stage 1 — app shell

The public app currently contains the four top-level navigation areas only:

- Calendar
- Playroom
- Scores
- Profile

No games, Firebase integration, account system, calendar-door logic or final pixel-art system has been added yet.

## Live app

https://chipbutt.github.io/Advent2026/

## Current structure

- `index.html` — app shell and four primary views
- `styles.css` — mobile-first shell styling
- `app.js` — simple hash-based navigation

The older Sandbox2 files remain in repository history. The root app is now the Advent 2026 project.
